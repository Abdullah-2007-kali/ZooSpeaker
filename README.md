# Animal Classifier with Text-to-Speech

A Python project that classifies animal images using a CNN model, fetches descriptive text from a JSON file, and converts it to speech using *edge-tts*.

---

## Features

- Classifies *10 different animal classes* using a pre-trained CNN model.
- Loads images via a *file selection GUI* using Tkinter.
- Fetches descriptive text for the predicted animal from a *JSON file*.
- Converts the descriptive text to *Arabic speech* using *edge-tts*.
- Plays the audio output directly using *pygame*.
- Fully object-oriented design with separate classes for CNN and Audio functionality.
